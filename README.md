# sbot
# Чат-бот для онлайн-школы

Удобный Telegram-бот, который помогает студентам быстро получать учебную информацию, а администраторам — управлять оповещениями и отвечать на вопросы.

## Инструменты для реализации:
> - Python 3.11
> - pyTelegramBotAPI (telebot)
> - Форматирование текста: Markdown / HTML и удобные кнопки (Reply / Inline)

## Проект состоит из:
> - **Обработка текста:** бот понимает команды и обычные текстовые запросы от учеников (расписание, домашки, полезные ссылки).
> - **Понятный интерфейс:** ответы оформлены красиво и без каши — с абзацами, эмодзи, списками и кнопками, чтобы ученикам не приходилось вчитываться в простыни текста.
> - **Админка:** команды для кураторов и админов (отправить объявление всем сразу, посмотреть новые вопросы).
> - **Понятная документация:** 
>   - Гайд для студентов: как запустить бота, нажимать кнопки и быстро находить нужные уроки.
>   - Инструкция для админов: как запустить проект, куда вставить токен и как рассылать сообщения.
